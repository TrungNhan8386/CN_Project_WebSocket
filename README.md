# PJ_Socket

CÁCH CHẠY CHƯƠNG TRÌNH

-TERMINAL 1 : py Server.py 8000

-TERMINAL 2 : py ClientLauncher.py 127.0.0.1 8000 9000 movie.Mjpeg

Chạy thành công sẽ hiện một tab của Tkinter.

-Nhấn "Setup" để load video

-Nhấn "Play" để phát video

-Nhấn "Pause" để tạm dừng

-Nhấn "Teardown" để thoát chương trình

#Lưu ý : sau khi nhấn "Teardown" thì chỉ tắt Client còn Server vẫn chạy, bạn vẫn có thể chạy lại CLientLauncher.
